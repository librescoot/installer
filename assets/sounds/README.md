`boot.wav` is copied from [Librescoot boot-animation's `scooter-unlock.wav`](https://github.com/librescoot/boot-animation/blob/main/scooter-unlock.wav).

`toast-info.wav`, `toast-warning.wav`, `toast-error.wav`, `nav-start.wav`, `blinker-pulse.wav`, and `nav-hop.wav` are copied from [Librescoot scootui-qt sounds](https://github.com/librescoot/scootui-qt/tree/main/assets/sounds). These and `boot.wav` are licensed under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Installer cues: info for ordinary attention, warning for safety notices and manual power/reboot steps, error for failures, nav-start for confirmations, blinker-pulse when releasing a brake, nav-hop when pulling it again. `beat.wav` is an original metronome tone generated with `scripts/generate_sounds.py`.
